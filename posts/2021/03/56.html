제조간접비

공통비 => 기준에 의해 비분 (배부)

제조간접비의 배부

실제배부법 - 실제 제조간접비를 실제 배부기준에 의해 배부, 정확성 가액법
배부액 = 직접재료비(실제) 각 제품별 금액 X 배부율
- 직접재조비법 -> 배부율(직접재료비당) - 제조간접비 실제액/직접제조비 합계
- 직접노무비법
- 직접원가법  = 직접재료비 + 직접노무비
시간법
배부액 = 실제 각 제품 기계시간 X 배부율
- 노동시간법 -> 배부율(기계시간당 제조간접비) = 제조간접비(실제)/기계시간합계
- 기계시간법
예정배부법 (예정)배부율 = 예정제조간접비/예정배부(시간, 생산량(조업도))기준
예정배부액 = 실제배부기준(생산량) X 예정배부율

배부차이 = 실제제조간접비 - 예정배부액

제조원가 = 직접재료비 + 직접노무비 + 제조간접비

예정배부액 = 직접노무비 X 예정배부율

배부차이의 처리

매출원가 조정법 : 매출원가에 가산(차감)
영업외손익법 : 영업외비용(수익)으로 처리
비례배분법(제공품, 제품, 매출원가)

부문별원가계산 - 장소별 원가계산

제조부문 -> 생산 1부, 생산 2부, 조립부, 절단부 ... 
보조부문 -> 식당부문, 수선부, 전력부, 공장사무부
