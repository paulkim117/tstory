투자자산

<유가증권>

1. 단기매매증권 - 단기보유목적, 시장성, 공정가액 평가, 취득수수료 => 수수료 비용

2. 만기보유증권 - 만기보유목적, 주식불가, 평가x(상각후가액), 취득수수료 => 자산

3. 매도가능증권 - 장기투자목적, 공정가액평가, 취득수수료 => 자산

4. 지분법 적용 투자주식 - 지분율이 20%이상, 주식

<재분류>

1. 단기매매증권 <----X---> 다른 유가증권 (단, 시장성상실 => 매도가능증권)

2. 매도가능증권 <---------> 만기보유증권

토지 영업목적-> 토지
투기목적 -> 투자부동산
건물 영업목적 -> 건물
투기목적 -> 투자부동산

단기매매증권 평가손익 => 영업외손익 (손익계산서)

매도가능증권평가손익 => 재무상태표의 기타포괄손익누계액

매입채무 = 외상매입금 + 지급어음

매입환불 - 하자, 반품 VS 매출환입
매입에누리 - 하자, 값을 깎는것 VS 매출에누리
매입할인 - 외상대 조기 결제시, 이자혜택 VS 매출할인

1. 외상매입시(상품) 

(차) 상품 / (대) 외상매입금

2. 매입환출, 매입에누리

(차) 외상매입금 / (대) 매입환출및에누리(상품)

3. 외상대상환시

(차) 외상매입금 / (대) 현금

4. 상품매입시 어음발행

(차) 상품 / (대) 지급어음

5. 매출시 어음수취

(차) 받을어음 / (대) 상품매출

유동성대체 => 유동성장기부채
