1. 감가상각

1) 감가상각대상금액 = 취득원가(=구입가격 + 취득부대비용 - 할인)

2) 감가상각 시작시점 : 사용시점(구입시점 x)

3) 내용년수 : 사용가능한 예상년수

2. 감가상각방법 - 합리적 방법 선택

3. 감가상각 계산 - 원가배분

정액법 : 매년 동일한 금액, 직선법
감가상각비 = (취득원가 - 잔존가액) -> 상각대상금액/ 내용년수
(차) 감가상각비 / (대 ) 감가상각누계액
정율법 = 체감법(초기에 과대, 후반부 갈수록 과소 계상)
감가상각비 = (취득원가 - 감가상각누계액) X 상각율
                  => 장부가액, 미상각잔액,상각대상금액
생산량비례법(비례법)
감가상각비 = (취득원가 - 잔존가액) X 당해년도생산량/총예정생산량
연수합계법(체감법)
감가상각비 = (취득원가 - 잔존가액) X 내용년수의역순/내용년수합계

차감하는 형식의 기재 (간접법)

    건    물        100

감사상각누계액  (20)       80 = 장부가액 미상각잔액

무형자산

- 영업활동사용, 형체가 없는 자산

영업권 = 합병등에서 구입시 발생

(차) 자산 100 / (대) 부채 60

    영업권 10          현금 50

내부적 창출 무형자산

연구비 - 비용
개발비 - 무형자산 "개발비"

무형자산의 상각

1) 취득원가 = 구입가격 + 부대비용 - 할인 등

2) 잔존가액 = "0" (단, 시장이 있고, 구매약정 등이 있으면 인전)

3) 내용년수 = 법에 의한 경우를 제외하고 20년을 초과하지 않는 범위내

4) 상각방법 - 합리적 방법 (단, 합리적 방법 X -> 정액법)

5) 표시와 회계처리 => 직접법 상각

(차) 무형자산상각비 / (대) 영업권

재무상태표 => 무형자산 => 상각후 금액
