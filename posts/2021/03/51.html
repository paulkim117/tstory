사채

- 1년이상, 일정기일에 사채권의 액면가액을 지급하기로 약속하고 발생하는 유가증권

- 이자지급(액면이자육 X 액면금액) => 채무증권 VS 지분증권(배당)

- 대중으로부터 자금조달

(1) 사채의 발행방법

- 사채의 발행가액(현금입금액) = 액면가액의 현재가치 + 이자의 연금현재가치

                                        = 액면금액 X 현가계수 + 이자금액 X 연금현가계수

1. 액면발행 = 평가발행 : 액면금액 = 발행금액   ＊시장이자율 = 액면이자율
   (차) 현금(발행가액) / (대) 사채(액면금액)
2. 할인발생 : 액면가액 > 발생가액                  ＊시장이자율 > 액면이자율
   (차) 현금(발행가) / (대) 사채(액면가액)
         사채할인발행차금
3. 할증발행 : 액면가액 < 발행금액                  ＊시장이자율 < 액면이자율
   (차) 현금(발행가) / (대) 사채(액면가)
                                 사채할증발행차금

수수료 = 발행가액에서 차감처리 => 사채 할인 발행 차금에 가산

                                                사채 할증 발행 차금에서 차감

시장 이자율 = 시장에서 수요와 공급에 따른 이자율

유효 이자율 = 사채발행비 X => 시장이자율 = 유효이자율

                   사채발행비 O => 시장이자율 // 유효이자율

-면 환입 : (차) 퇴직급여충당부채 20 / (대) 퇴직급여충당부채환입(판관비) 20
