개별원가계산

주문생산방식
- 특정작업지시서
- 원가 계산표 => 제조간접비 배부
예정배부율 = 제조간접비예산/예정배부기준
예정배부액 = 실제배부기준 X 예정배부율
직접원가 = 직접재료비 + 직접 노무비
대량샌산방식
- 계속작업지시서
- 원가를 직접재료비와 가공비로 분류
- 완성품 환산량 계산 => 일한정도

1. 단일 종합원가 -> 하나의 제품에 하나 공정
2. 공정별 종합원가 -> 하나의 제품에 둘 이상 공정
3. 조별 종합원가 -> 둘 이상의 제품에 둘 이상의 공정
4. 등급별 종합원가 -> 하나의 원재료로 질이 다른 둘 이상의 상품
5. 연산품 종합원가 -> 하나의 원재료로 동질의 다른 제품과 부산물

종합원가 계산의 절차 (5단계법)

1단계 : 물량 흐름 파악

2단계 : 완성품 환산량 계산

직접재료비 vs 가공비

- 평균법 : 기초와 당기착수완성분 구분 안함

- 선입선출법 : 기초분과 당기착수분을 구분(당기착수분이 기말새공품에 포함) => 기초분이 먼저 완성

3단계 : 원가집계

- 평균법 : 기초 + 당기투입원가

- 선입선출법 : 당기투입원가(제조원가)

4단계 : 단위당원가 =원가/수량

5단계 : 원가배분

- 완성원가

- 기말제공품원가
