1. 매출채권

- 외상매출금 + 받을어음

  매출(상품매출, 제품매출) 매입(상품, 원재료)
외상 어음 외상 어음
상거래 O 외상매출금 받을어음 외상매입금 지급어음
상거래 X 미수금 미수금 미지급금 미지급금
매출환입 물건하자 => 반품 매출할인 및 에누리
매출에누리 물건하자 => 값을 깎는 것
매출할인 외상대조기결제 -> 할인 매출할인

4. (차) 매출할인및에누리 - / (대) 외상매출금 - // 상품 하자로 인한 반품 시

2. 받을어음

약속어음 : 어음발행인 수취인에게 지급약속
환어음 : 어음발행인이 어음발행, 지급인(은행)이 수취인에게 어음대금 지급

[매출, 매입시]

A상점 (차) 상품 100,000 / (대) 지급어음 100,000

B상점 (차) 받을어음 100,000 / (대) 상품매출 100,000

[결제시]
