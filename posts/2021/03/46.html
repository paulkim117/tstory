1. 수량결정방법

계속기록법 입고시 마다 수량을 기록, 출고시 마다 수량 기록 ＊모르는 것 => 역산
기말수량 = 기초수량 + 순매입수량( = 판매가능수량) - 매출수량
-> 감모(도난, 증발, 분실)수량이 기말수량에 합산
실지재고조사법 입고는 기록, 출고는 기록안함, 기말수량을 실사
매출수량 = 기초수량 + 순매입액 - 기말실사수량
매출수량에 감모가 포함됨
혼합법 계속기록법(장부상 기말수량) + 실지재고조사법(기말재고실사)

2. 단가결정방법

개별법 라벨을 보고 매출단가와 기말재고단가를 결정
장점 : 정확성, 실제물량흐름과 단가흐름이 완전일치
단점 : 시간과 비용이 많이 소요 => 귀금속, 사치품에 사용
선입선출법(FIFO) 먼저입고 -> 먼저출고, 기말재고 나중 입고 분
장점 : 실제물량흐름과 단가흐름이 일반적으로 일치
        기말재고 => 시가에 근접(현행가치 반영)
단점 : 이익과대 -> 세금이 초기에 과대 => 자금흐름 악화
후입선출법(LIFO) 나중입고 -> 먼저출고, 재고 -> 먼저입고분
장점 : 재고과소 -> 이익과소 -> 세금초기 과소납부 -> 자금흐름 개선
        현행수익에 현행원가 가 대응 => 수익과 비용이 적정대응
단점 : 기말재고 시가를 반영못함
        실제물량흐름과 단가흐름이 불일치
        경영성과가 왜곡
이동평균법 입고시마다 평균단가 재산정
평균단가 = 매입직전금액 + 매입금액/(매입직전수량 + 매입수량)
장점 : 간편, 이익조작가능 X, 물가를 민감하게 반응
총평균법 => 기말실사법 기말에 한법 평균단가 산출
평균단가 = 기초금액 + 매입액/기초수량 + 매입수량

재고크기(이익) = 선입선출법 > 이동평균법 > 총평균법 > 후입선출법

미착품 선적지인도기준 : 배에 인적시점에서 매입자 것 (운임포함)
도착지인도기준 : 도착시 매입자의 것 (판매자의 운반비)
위탁품(적송품) 판매하기위해 수탁자에게 보낸 재고
매출인식 - 수탁자가 판매시 (수탁자가 판매하기 전에는 우리재고)
시송품 사용 후 만족시 구매의사표시
매출시기 - 구매의사표시시 (구매의사 표시전까지는 우리재고)
할부판매시 대금을 나눠서 수취
매출시기 - 인도시점 (이자부문)
               단, 중소기업 => 회사기일기준 선택

3. 재고자산감모손실과 재고자산평가손실

1. 재고자산감모손실

-도난, 분실, 증발등에 의해 감소된 수량

- 감모손실 = (장부수량 - 실사수량) X 취득가액

본계정 대체 상품 => 상품매출원가
제품 => 제품매출원가
원재료 => 원재료비

정상 -> 원가성 O => 매출원가 (기초상품+순매입액-기말상품)

비정상 -> 원가성 X => 손실(영업외비용) (차) 재고자산감모손실 / (대) 상품(타계정대체)

2. 재고자산평가손실

- 실사수량 X [취득단가 - 시가(순실현가치 - 상품.제품 등, 현행대체원가 -> 원재료)]

-> 저가법 - 시가와 원가 중 작은 값으로 재고가액 결정

(차) 재고자산평가손실 (매출원가) / (대) 재고자산평가충당금 (재고차감)

     -> 평가손실
